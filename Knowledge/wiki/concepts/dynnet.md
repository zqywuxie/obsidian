# DynNet 随机动力学推断网络

## 简介

DynNet（Stochastic Dynamics Inference Network）是一种将神经常微分方程（Neural ODE）与生物物理模型及先验知识整合的深度学习方法，用于从多时间点 scRNA-seq 数据推断细胞命运的随机动力学。

由 Dou, Lyu, Chen, Nie & Li 发表于 Nature Communications (2026)。

## 核心框架

### 随机微分方程

DynNet 将细胞状态演化建模为 SDE：

```
dx = f(x)dt + σ(x)dW
```

- **漂移项 f(x)**：基因调控驱动，使用 Hill 函数编码激活/抑制/降解
- **扩散项 σ(x)**：随机噪声（内在生化波动 + 外部环境扰动）
- **dW**：标准布朗运动

### 希尔函数基因调控

基因 i 的动力学：

```
f_i(x) = Σ a_ij·x_j^nh/(S_j^nh + x_j^nh) + Σ b_ij·S_j^nh/(S_j^nh + x_j^nh) - k_i·x_i
```

- a_ij: 激活强度，b_ij: 抑制强度
- S_j: 半最大效应浓度（阈值）
- k_i: 降解率，n_h: 希尔系数（=4）

### 先验约束

- **硬约束**：屏蔽先验 GRN 中不存在的边，适合先验可靠时
- **软约束**：L2 惩罚非先验边，允许发现潜在调控关系

### 损失函数

复合损失 = 动力学一致性损失 + 权重匹配损失 + 约束正则项

## 应用场景

1. **发育生物学**：从多时间点 scRNA-seq 重建分化轨迹和能量景观
2. **肿瘤可塑性**：分析 EMT/MET 过程中的状态转换和关键调控基因
3. **基因扰动模拟**：in silico 敲除实验预测基因对命运决定的影响
4. **细胞命运预测**：基于决策边界预测未确定状态细胞的未来命运

## 输入输出

### 输入
- 多时间点 scRNA-seq 数据（4-6 时间点最优）
- 先验 GRN（可选，支持无先验的纯数据驱动模式）
- 核心基因集（非全基因组）

### 输出
- 能量景观（吸引子、鞍点、能垒）
- 速度场 / 决策边界
- 转变路径 + 转变作用量
- 关键调控基因鉴定
- 扰动模拟（敲除、过表达）

## 与相关方法对比

| 特性 | DynNet | Neural ODE | RNA velocity | Markov 模型 |
|------|--------|------------|--------------|-------------|
| 随机动力学 | ✓ | ✗ | ✗ | △ |
| 基因可解释性 | ✓（Hill 函数） | ✗（黑箱） | △（剪接） | ✗ |
| 多稳定态 | ✓ | ✗ | △ | ✓ |
| 先验知识整合 | ✓ | ✗ | ✗ | ✗ |
| 能量景观 | ✓ | ✗ | ✗ | ✗ |
| 扰动模拟 | ✓ | △ | ✗ | ✗ |

## 局限性

- 需假设系统最终收敛到准稳态（不适用于振荡过程如细胞周期）
- 受限于核心基因集（目前无法处理全转录组）
- Hill 函数刚性结构约束了动力学灵活性
- SDE 数值积分计算强度大
